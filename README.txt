bmstrainer ver 0.1.2（テスト版）

English: README_en.txt / 한국어: README_ko.txt
====================================

BMS 譜面の練習用ツールです。

  ・譜面の速度を変える（BPM 指定 / LR2 と同じ FREQ 指定、ピッチを変えるかどうか）
  ・判定（EASY / NORMAL / HARD）を変える
  ・osu!mania（7K / 8K）の譜面を BMS に変換する
    本体の BMS があれば、そのキー音をノーツに割り当てる

元の譜面は書き換えず、同じフォルダに別の譜面として作成します。


■ 動作環境

  Windows 10 / 11（64bit）
  .NET などを別途インストールする必要はありません。


■ 起動

  bmstrainer.exe を実行してください。
  binaries フォルダは bmstrainer.exe と同じ場所に置いたままにしてください。

  初回起動時に「Windows によって PC が保護されました」と表示された場合は、
  「詳細情報」→「実行」で起動できます（署名していない exe のため表示されます）。


■ 表示言語

  日本語・英語・韓国語に対応しています。最初は Windows の言語に合わせて表示され、
  メイン画面右下の選択欄で切り替えられます（再起動後に反映）。


■ 譜面の速度・判定を変える

  1. 「譜面を開く…」「フォルダを開く…」またはドラッグ＆ドロップで譜面を開き、
     差分を選びます。
  2. 速度を指定します。
       BPM 指定  … 目標の BPM（一番長く続く BPM 基準）を入力
       FREQ 指定 … -12 ～ +12 から選択（1 段 = 半音。LR2 と同じ倍率）
  3. 「ピッチを変える」
       オン  … 音程も一緒に上がる／下がる（LR2 の FREQ と同じ）
       オフ  … 音程を保ったまま速さだけ変える
  4. 必要なら判定を選びます（変更しない / EASY / NORMAL / HARD）。
  5. 「作成する譜面の名前」でタイトル・サブタイトル（差分名）・ファイル名を
     変更できます。何も触らなければ自動の名前（例: [FREQ+1]）が付きます。
  6. 「譜面を作成」を押します。

  作成されるもの
    ・譜面        … 元の譜面と同じフォルダ
    ・キー音      … 譜面フォルダ内の _bmstrainer フォルダ（WAV 形式）
  「生成した譜面を削除…」で、そのフォルダに作成した譜面とキー音をまとめて削除できます。


■ osu! 譜面を BMS に変換する

  メイン画面右上の「osu! 譜面を変換…」から使います。

  1. osu! 譜面（.osu / .osz）を開き、差分を選びます。
  2. 本体フォルダ（任意）
       指定しない … osu! の音源を BGM として鳴らす譜面を、「出力先」のフォルダに作成します。
       指定する   … 本体 BMS のキー音をノーツに割り当てた譜面を、本体フォルダに作成します。
                    本体フォルダの差分のうち、キー音が一番一致するものを自動で基準にします。
                    オフセット（osu! の音源と本体のずれ）も自動で検出します。
                    「キー音の一致率」が低い場合は、基準の譜面やオフセットを調整してください。
  3. 判定・名前を確認して「変換」を押します。

  本体に音が無い位置のノーツは無音になります。


■ 注意

  ・作成したキー音は WAV 形式のため、フォルダの容量が増えます。
  ・BGA の動画は速度が変わらないため、映像がずれます。
  ・osu! 変換は 7K / 8K のみ対応です（8K は左端がスクラッチ）。SV（緑線）は反映しません。
  ・テスト版です。作成した譜面は念のため確認してから遊んでください。


■ 設定・アンインストール

  設定は %APPDATA%\bmstrainer\settings.json に保存されます。
  アンインストールは、このフォルダと上記の設定フォルダを削除するだけです。
